# 学习效率重构

用户反馈：对白和页面步骤增加认知成本，要求重构级改变。

## 行为契约
- 课程以可完成的任务为入口，明确目标、已知条件、动作和结果。
- 阅读主流程为目标与机制 → 示例与解释 → 实践反馈。故事为可选辅助，不再独占第一阶段。
- 主线、参考补页、AI 项目分开；下一课不强制经过选修页；保留原有深链接。
- 零基础入口提供运行、变量、条件、返回值的微阶梯，再进入完整工程代码。
- 保留已有编辑器、运行沙箱、代码草稿与后端验收凭证，不把阅读记录标为代码掌握。
- 不删源稿、不再生成图片，不重写尚未实质审查的技术结论。

## 实施计划
1. 审查教学断层（完成：8 项静态发现）。
2. 重构路线导航、阅读完成与验收分类。
3. 重构页面内容层级，加入可运行基础阶梯。
4. 校验桌面/手机、深链接、补页退出、示例运行和练习入口。
5. 两轮独立审查并记录未完成事项；不虚报学习效果分数。

## 验收
主线下一课 chapter-1→chapter-2；项目独立可见；普通补页可标记阅读而不请求项目验收；对话默认折叠；技术内容与代码同阶段可查；新手引导能运行且给具体预期；导航和编辑无浏览器错误；不丢旧进度/草稿。
