# 全工程中文文案重构

用户要求：像自然中文教程，避免英语硬翻译、术语堆砌和审核报告口吻。

## 写作约定
- 先写具体问题/动作/结果，再给中文名称与必要英文标识。一个句子只推进一件事。
- 标题用“怎样做/出错怎么办”，目标是可执行动作，不是“掌握A、B、C”。
- 机制解释用完整短段落，说明因果；不要“物理尝试、稳定身份、收口、证据闭环、边界钉牢”等悬空词。
- 中文解释优先，代码/API/状态常量保持原名。专业限制放独立提示并解释原因，不删技术要求。
- 参考官方Go教程“问题→代码→改一个输入→观察输出”、Go by Example“一例一事”的讲解结构；原创表述，不复刻文章。

## 实施
1. 外部参考与内容字段清点。
2. 按Go、后端、AI三卷重写全部79单元可见文案，分文件源层保存；同步课前简述与对白。
3. 清理界面提示与术语说明；练习命令、函数签名、枚举、判分序号与后端验证保持不变。
4. 同步到生成链；全量字段覆盖/不可变数据检查；逐卷复审与桌面/手机样例检查。

来源： https://go.dev/doc/tutorial/handle-errors 、https://gobyexample.com/errors 、https://gobyexample-cn.github.io/ 。

文案源格式：manuscript/plain-language/{go,backend,harness}.json，顶层units[id]为字段路径→替代值，briefs[id]为task/why/mechanism/check。路径是点分字符串，仅替换文字/文字列表，不改代码、选项顺序/含义、IDs、正确答案索引、运行证明字段。
