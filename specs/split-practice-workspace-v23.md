# v23 分屏实践教学工作台

## 问题

当前章节是单页长流，学习者需要在代码、解释和练习之间频繁上下滚动。顶部三阶段按钮会直接滚动整页，不符合初学者的连续实践节奏。

## 目标

1. 桌面端为左讲解、右代码的双栏工作台。
2. 移动端使用“讲解 / 代码”两个标签，切换时不重建 DOM 或编辑器。
3. 每课显示五个连续小步骤：定位问题、运行观察、理解规则、自己动手、验证过关。
4. 运行反馈始终留在代码面板，不抢焦点、不自动切标签。
5. 过关清单和下一课检查能先打开正确面板，再定位缺项。
6. 保留所有现有课程数据、运行 API、证明字段和完成判定。

## 布局契约

- 讲解面板：五步导航、场景问题、必要规则、按需展开、补页和下一课提示。
- 代码面板：参考代码与预测、独立练习、过关清单。
- 两个面板各只有一套 DOM；禁止为桌面和移动克隆编辑器。
- 移动标签使用 `tablist/tab/tabpanel` 语义，隐藏面板同时设置 `hidden` 与 `inert`。
- 切回某面板时恢复该面板在当前单元内的相对阅读位置。

## 验收

- 1440px 下同时可见讲解与代码两栏，无横向溢出。
- 390px 下仅显示当前标签面板，隐藏面板不能被 Tab 聚焦。
- 讲解/代码往返后位置误差不超过 12px。
- 基础课、普通 Go 课、Agent quickstart 和项目实验仍能运行。
- 缺项定位会先切换到目标面板，再滚动和聚焦。
- 亮色/暗色 axe 违规为 0，学习流审计通过。
